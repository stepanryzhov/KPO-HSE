# ВышBuild

ВышBuild принимает сдачи домашних работ в ZIP и формирует отчёты для студентов и преподавателей.

## Запуск

Из корня проекта запустите три сервиса через Docker Compose.

```bash
docker compose up --build
```

Ту же команду запускает `make up`. Gateway доступен по адресу `http://localhost:8080`. Тесты запускаются командой `go test ./...`.

`make clean` удаляет контейнеры, сеть, собранные образы и том `storage_data` с архивами и базой SQLite.

## Архитектура

- **Gateway** принимает запросы клиентов и управляет синхронными HTTP-вызовами.
- **Storage** хранит ZIP на диске, а метаданные и отчёты в SQLite. Размещение метаданных и отчётов в одном сервисе позволяет собрать сводку одним запросом к базе.
- **Analyze** проверяет архив. Обычный файл `main.go` на любой глубине даёт `passed`, его отсутствие даёт `failed`. Имя файла служит простым признаком ожидаемой точки входа Go-проекта.

### Сценарий сдачи

1. Gateway передаёт ZIP в Storage. Storage проверяет и сохраняет архив, затем возвращает `submission_id` и `archive_key`.
2. Gateway вызывает Analyze с этими идентификаторами. Analyze получает ZIP из Storage и возвращает отчёт.
3. Gateway записывает отчёт в Storage для текущего ключа архива и отвечает клиенту в том же запросе.

### Обработка сбоев

- При недоступности или таймауте Storage либо Analyze Gateway возвращает `503` с сообщением. Если Storage уже подтвердил сохранение архива, ошибка POST включает `submission_id`.
- При сбое Analyze сохранённая сдача видна с `report: null`. Готовые отчёты можно читать через Storage.
- Если более свежая пересдача заменила архив во время проверки, предыдущий POST получает `409` с `submission_id`.

## API

Пример загрузки файла `submission.zip` для задания `hw3` и студента `42`.

```bash
curl -i 'http://localhost:8080/assignments/hw3?student_id=42' \
  -H 'Content-Type: application/zip' \
  --data-binary @submission.zip
```

Первая сдача возвращает `201`, пересдача возвращает `200` с тем же `submission_id`. Лимит ZIP по умолчанию составляет 10 МиБ. Некорректный или слишком большой архив получает `400`.

| Запрос | Результат |
| --- | --- |
| `GET /assignments/hw3?student_id=42` | Текущая сдача студента и её отчёт |
| `GET /assignments/hw3` | Сводка со счётчиками успешных, неуспешных и оставшихся без отчёта сдач |

Для обоих GET Gateway читает данные из Storage и по умолчанию возвращает JSON. Добавьте `format=html`, чтобы открыть отчёт или сводку в браузере.
