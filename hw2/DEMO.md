# Запуск и демонстрация ПОС

Все команды выполняются из корня проекта.

## Обычная работа

```bash
make run
```

Студенты сохраняются в `data/students.json`, ведомости — в `data/gradebooks/`.
При запуске открывается `default`. Изменения сохраняются после каждой успешной
операции.

Пункт 13 показывает ведомости по названиям. Выберите номер существующей ведомости
или действие «Создать новую ведомость» и введите название, например `КПО`.
Файл будет создан автоматически. Для возврата в меню выберите `0`, а при вводе
названия можно оставить строку пустой. Общий реестр студентов один для всех
ведомостей; состав студентов, критерии и оценки у каждой свои.

Перед вводом ID программа показывает подходящих студентов и критерии. В списках
можно ввести `0`, чтобы вернуться в меню. При исправлении оценки видны текущие
баллы и максимум выбранного критерия. Для отмены предлагаются только выставленные
оценки. Существующий CSV перезаписывается после явного подтверждения; пустой ответ
означает отказ.

## Готовая ведомость для презентации

```bash
make demo
```

Этот режим открывает отдельную временную копию демонстрационных JSON.
При следующем запуске данные снова исходные. Экспортированный CSV остаётся
по выбранному пользователем пути.

В меню можно показать:

1. Пункт 2 — общий реестр студентов.
2. Пункт 6 — критерии и веса.
3. Пункт 11 — таблицу всех оценок и итогов.
4. Пункт 7: студент `1`, критерий `1`, балл `11` — отказ по ограничению максимума.
5. Пункт 7: студент `1`, критерий `1`, балл `10` — исправление оценки.
6. Пункт 10: студент `1` — новый итог `9.75`.
7. Пункт 12 — экспорт таблицы в CSV.
8. Пункт 0 — выход.

Исходная таблица:

| Имя | Домашние работы | Проект | Экзамен | Итог |
|---|---:|---:|---:|---:|
| Анна Смирнова | 8 | 9 | 10 | 9.25 |
| Борис Иванов | 7 | 8 | 9 | 8.25 |
| Вера Петрова | 10 | 9 | 8 | 8.75 |

Итог: `домашние работы × 0.25 + проект × 0.25 + экзамен × 0.5`.
Для расчёта и экспорта нужны оценки по всем критериям.

## Автоматический сквозной сценарий с нуля

```bash
demo_dir=$(mktemp -d)
go build -o "$demo_dir/pos" ./cmd/app
cp cmd/app/demo/presentation.txt "$demo_dir/presentation.txt"
(cd "$demo_dir" && ./pos < presentation.txt)
```

Сценарий создаёт студентов и критерии, выставляет оценки, показывает ведомость,
отклоняет балл выше максимума, исправляет и отменяет оценку, восстанавливает её
и экспортирует результат в `$demo_dir/demo-results.csv`. Новая временная папка позволяет
повторять сценарий без перезаписи предыдущего экспорта.
В конце итог Анны равен `9.75`, Бориса — `8.25`, Веры — `8.75`.

Для интерактивного просмотра сохранённых результатов можно повторно открыть
те же файлы без перенаправления ввода:

```bash
(cd "$demo_dir" && ./pos)
```
